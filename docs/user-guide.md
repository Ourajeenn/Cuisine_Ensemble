# Guide utilisateur CuisineEnsemble

## Accès

1. Ouvrir l’URL publique de l’application.
2. Créer un compte ou se connecter.
3. Naviguer entre les repas, la messagerie et la création d’un repas.

## Fonctionnalités principales

### Trouver un repas

- filtrer par type de cuisine ou par régime alimentaire
- rechercher par nom, quartier ou cuisine

### Proposer un repas

- renseigner le lieu, l’horaire, le nombre de places et le mode de paiement

### Communication

- échanger dans le chat de la session de repas

## Support

En cas de souci :

- recharger la page
- vérifier la connexion
- contacter l’administrateur
